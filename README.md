# viemm

TypeScript interface for Ethereum — lightweight, modular, modern

## Overview

A modern TypeScript library for interacting with Ethereum. Built with tree-shaking in mind — import only what you need.

## Features

- Lightweight — 5x smaller than alternatives
- Tree-shakeable imports
- Built-in ENS resolution
- Transaction simulation
- Wallet connection helpers

## Installation

```bash
npm install viemm
```

## Quick Start

```javascript
npm import viemm
```
